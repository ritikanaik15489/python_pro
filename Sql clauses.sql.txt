Clauses:-These clauses are used to select, filter, group, and combine data from one or more tables

1. WHERE Clause – 
The WHERE clause is used to filter individual rows from a table. 

Syntax – 
SELECT column1, column2 
FROM table_name 
WHERE condition;

Common operators with WHERE – 
Operator  Meaning  Example 
=  Equal to  salary = 50000 
>  Greater than  salary > 50000 
<  Less than  salary < 50000 
>=  Greater than or equal  salary >= 50000 
<=  Less than or equal  salary <= 50000 
<>  Not equal  department <> 'HR' 
AND  Both conditions true  salary > 40000 AND department = 'IT' 
OR  Either condition true  department = 'IT' OR department = 'HR' 


2. BETWEEN Operator - 
The BETWEEN operator is used to select values within a specified range. 
It includes both the starting and ending values. 
Syntax –  
  SELECT column_name  FROM table_name 
WHERE column_name BETWEEN value1 AND value2;

Ex:-

mysql> select * from employee
    -> where salary between 40000 and 50000;
+--------+-------+-------+----------+
| emp_id | name  | dep   | salary   |
+--------+-------+-------+----------+
|    101 | Rahul | IT    | 50000.00 |
|    102 | Priya | HR    | 40000.00 |
|    104 | Sneha | Sales | 45000.00 |
+--------+-------+-------+----------+
3 rows in set (0.00 sec)


3. IN Operator -  
The IN operator is used to check whether a value matches any value in a list. 
It is useful when we have multiple possible values. 
Syntax –  
SELECT column_name FROM table_name 
WHERE column_name IN (value1, value2, value3); 

Ex:-

mysql> select * from employee
    -> where dep='it'
    -> or dep='hr';
+--------+-------+------+----------+
| emp_id | name  | dep  | salary   |
+--------+-------+------+----------+
|    101 | Rahul | IT   | 50000.00 |
|    102 | Priya | HR   | 40000.00 |
|    103 | Amit  | IT   | 60000.00 |
+--------+-------+------+----------+
3 rows in set (0.00 sec)

If it not found then it will give an empty set.

mysql> select * from employee
    -> where salary between 90000 and 30000;
Empty set (0.00 sec)

6.IS NULL 
To find records containing NULL, use IS NULL. 
Syntax – 
  SELECT * FROM table_name
